# Бот-консультант для группы ВК (рассада, цветы, овощи)

## Что делает бот

- Отвечает в сообщениях группы с ИИ: уход, посадка, болезни, вредители, а также товары, цены, наличие, доставка, оплата.
- Понимает фото: человек присылает фото растения и спрашивает, что с ним.
- Сам подтягивает каталог из Маркета и альбомов и обновляет его каждые 30 минут.
- Записывает заказы из комментариев под фото в альбомах («беру 3», «+», «2 шт», «возьму пару»), отмены («отмена» или удалённый комментарий) и шлёт админам уведомление со ссылкой на фото.
- Ловит новые заказы из Маркета и смену их статуса.
- Кнопки у покупателя: «Мои заказы», «Позвать менеджера».
- Зовёт менеджера сам, если человек жалуется, просит возврат или бот не знает ответа. После этого бот молчит в этом диалоге 12 часов.
- Если менеджер сам ответил человеку из группы, бот тоже замолкает в этом диалоге.

Цены, доставку и правила бот берёт только из каталога и файла `knowledge.md`, не выдумывает.

## 1. Настройка группы ВК

1. Управление → Сообщения: включить сообщения сообщества.
   Там же → Настройки для бота: включить «Возможности ботов» и «Добавить кнопку Начать».
2. Управление → Работа с API → Ключи доступа → Создать ключ.
   Права: сообщения, фотографии, товары, управление сообществом. Это `VK_GROUP_TOKEN`.
3. Работа с API → Long Poll API: включить, версия API 5.199.
   Типы событий отметить:
   - Сообщения: входящее сообщение, исходящее сообщение
   - Фотографии: добавление комментария, удаление комментария
   - Товары: новый заказ, редактирование заказа
4. ID группы — цифры из Управление → Основная информация (или из ссылки club123456). Это `VK_GROUP_ID`.

## 2. Ключ для альбомов (VK_READ_TOKEN)

Ключ сообщества не умеет читать фото в альбомах и писать комментарии, поэтому нужен второй ключ:

- проще всего: сервисный ключ своего приложения ВК (vk.com/apps?act=manage → создать приложение → Настройки → «Сервисный ключ доступа»). Его хватит, чтобы читать открытые альбомы и Маркет;
- чтобы бот ещё и отвечал в комментариях под фото («Записали: Петуния × 3»), нужен ключ пользователя-админа группы с правами photos, market, groups, offline.

Ключ пользователя даёт доступ к аккаунту, храни его только в `.env` и никому не показывай.
Без `VK_READ_TOKEN` бот всё равно будет отвечать в сообщениях и ловить заказы Маркета, но не увидит альбомы.

## 3. Ключ ИИ

Создай ключ на console.anthropic.com (API Keys) и пополни баланс. Это `ANTHROPIC_API_KEY`.
API Anthropic работает не во всех странах, поэтому сервер для бота лучше брать в стране, где он доступен (например, VPS в Европе).

Модель: `claude-haiku-5-5` дешевле и быстрее, для консультаций её обычно хватает. `claude-sonnet-5-5` умнее, но дороже.

## 4. Запуск

Нужен Python 3.10 или новее.

```
pip install -r requirements.txt
cp .env.example .env      # и заполни .env
python bot.py
```

Заполни `knowledge.md`: доставка, оплата, самовывоз, сезон, частые вопросы. Это главное, от чего зависит качество ответов. Бот перечитывает файл при каждом ответе, перезапускать не нужно.

Админы из `ADMIN_IDS` должны хотя бы раз написать в сообщения группы, иначе ВК не даст боту присылать им уведомления.

## 5. Чтобы бот работал круглосуточно

Нужен сервер, который не выключается: любой недорогой VPS. Пример службы systemd (`/etc/systemd/system/vkbot.service`):

```
[Unit]
Description=VK shop bot
After=network.target

[Service]
WorkingDirectory=/opt/vkbot
ExecStart=/usr/bin/python3 /opt/vkbot/bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Затем: `systemctl enable --now vkbot`, логи: `journalctl -u vkbot -f`.

## 6. Команды для админов (писать в сообщения группы)

- `/заказы` — последние активные заказы
- `/вкл 123456` — снова включить бота для человека (после вызова менеджера)
- `/выкл 123456` — выключить бота для человека
- `/обновить` — обновить каталог сейчас

## Про «Полку СП»

Если перейдёшь на «Полку СП», заказы будет собирать она, а бот продолжит отвечать на вопросы. Тогда в `.env` поставь `REPLY_IN_COMMENTS=0`, чтобы бот не дублировал её ответы под фото.

## Тесты

Логика бота (разбор комментариев, заказы, отмены, ответы ИИ, каталог, команды админов) покрыта тестами, которые работают без ключей и без интернета:

```
pip install -r requirements-dev.txt
python -m pytest
```

На GitHub тесты запускаются сами при каждом изменении.

### Как бот понимает комментарии под фото

- Заказ: «+», «беру 2», «возьму пару», «бронь», «закажу 3», «2 шт», просто «3», «мне тоже», «хочу 2».
- Не заказ: «хочу узнать цену», «мне кажется, это не томат», «берёза красивая».
- Вопрос («сколько стоит 1 шт?», «бронь есть?») — бот отвечает в комментарии, заказ не записывает. Если в вопросе есть «+», «беру» или «возьму» («беру 2, когда отправка?»), это заказ.
- Отмена: «отмена», «не буду», «передумала» или удалённый комментарий. Отменяется только заказ этого человека под этим фото; если заказа не было, админам ничего не приходит.
- Комментарии админов из `ADMIN_IDS` заказами не считаются.
- Количество словами больше десяти («пятнадцать») бот не угадывает и пишет 1, админ увидит исходный текст комментария в уведомлении.

## Что важно проверить при первом запуске

Код покрыт тестами, но с настоящей группой ещё не запускался. После запуска:
1. Напиши группе «Начать», потом вопрос про рассаду и пришли фото растения.
2. Посмотри в логах строку «Каталог: N позиций» — если 0, проблема с `VK_READ_TOKEN`.
3. Оставь тестовый комментарий «беру 2» под фото в альбоме и проверь, что админу пришло уведомление.
