# План: бот-консультант для группы ВК (рассада)

## Что уже есть
- `bot.py`: бот на VK Long Poll + Claude API.
  - Отвечает в сообщениях группы (уход, болезни, цены, наличие, доставка), понимает фото растений.
  - Подтягивает каталог из Маркета и альбомов, обновляет каждые 30 минут.
  - Принимает заказы из комментариев под фото («беру 3», «+», «отмена»), уведомляет админов.
  - Ловит заказы Маркета и смену их статуса.
  - Кнопки «Мои заказы» и «Позвать менеджера»; после вызова менеджера или ручного ответа молчит 12 часов.
  - Команды админов: `/заказы`, `/вкл`, `/выкл`, `/обновить`.
- `knowledge.md`: шаблон базы знаний магазина (пока не заполнен).
- `README.md`: инструкция по настройке группы, ключей и запуску.
- `.env.example`: все настройки.

## Что сделать дальше
1. Заполнить `knowledge.md` реальными данными магазина (оплата, доставка, самовывоз, сезон, FAQ).
2. Настроить группу ВК и получить ключи: `VK_GROUP_TOKEN`, `VK_READ_TOKEN`, `ANTHROPIC_API_KEY` (README, разделы 1–3).
3. Арендовать VPS в стране, где доступен API Anthropic, запустить бота как службу systemd (README, раздел 5).
4. Первый живой тест (код с настоящей группой ещё не запускался):
   - «Начать», вопрос про рассаду, фото растения;
   - в логах «Каталог: N позиций» больше нуля;
   - тестовый комментарий «беру 2» под фото доходит админу.
5. По итогам теста поправить разбор комментариев и ответы.
6. Если перейдём на «Полку СП»: `REPLY_IN_COMMENTS=0`.
